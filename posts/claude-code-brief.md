AIにコードを書いてもらうとき、依頼の仕方で出来上がりが大きく変わります。手戻りを減らすために、頼む前に決めておくことを4つに整理します。

## 1. 目的を一言で

「誰が、何のために使うか」を、最初に1行で書きます。画面の見た目より先に、使う場面を伝えます。

## 2. 入力と出力を例で見せる

言葉で説明するより、例を1つ見せるほうが伝わります。

```text
入力: A-001, 20個
出力: 在庫表のA-001の行が、20個ぶん減る
```

## 3. 範囲を区切る

一度に全部を頼まず、動く最小のものから始めます。

- まず、読み込みと表示だけ
- 次に、並べ替えと絞り込み
- 最後に、見た目の調整

### 区切るとよい理由

途中で確認できるので、方向が違っても早く直せます。

## 4. 確認の方法を決めておく

作ったあとに、何をどう確かめるかも伝えます。

- 数字が合うか(例で確認)
- 画面がスマホ幅で崩れないか
- 失敗したときの表示

## まとめ

目的、例、範囲、確認の4つを決めてから頼むと、やり直しが減ります。自分で判断する部分(何を載せるか、どんな言い方にするか)は、AIに任せず、自分で決めます。
