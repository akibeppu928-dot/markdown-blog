ビルドが通っても、公開前に見ておきたいことがあります。自分が使っている順に書きます。

## 1. ビルドとリンクの確認

```bash
npm run build
npm run start
```

ビルドが通ったら、ローカルで起動して、一覧から各記事へ移動できるかを確かめます。

## 2. 個人情報が入っていないか

公開するファイルに、電話番号やメールアドレス、APIキーが入っていないかを検索します。

```bash
grep -rnE "[0-9]{2,4}-[0-9]{2,4}-[0-9]{4}|@[a-z0-9.-]+\.[a-z]{2,}" app lib posts
```

画像は、位置情報(GPS)が入っていないかも確認します。

## 3. スマホ幅の表示

- 見出しが、言葉の途中で折れていないか
- 横にはみ出して、横スクロールが出ていないか
- ボタンや目次のリンクが、指で押しやすい大きさか

### 見る幅の例

320、375、390、430ピクセルの幅で見ます。実機でも1回は確認します。

## 4. 公開後

1. 公開URLが開くか
2. 記事のURLを直接開いても表示されるか
3. 存在しないURLで、きちんと「見つかりません」が出るか

## まとめ

公開前の確認は、あとで直すより早く終わります。チェックの項目は、自分の失敗に合わせて増やしていきます。
